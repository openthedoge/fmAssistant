## 中文说明

### 这是什么

这是我为了方便自己打自由人模式做的小工具，包含三个部分：

1. **首领辨认器**：选 3 个外观特征 + 1 个发色，实时显示可能的 2 位或 4 位候选首领。点候选图可以变灰，标记「已排除」。
2. **道具分布**：19 张地图、163 个道具的获取位置。支持搜索，可空格叠加多个关键词，例如 `巴黎 手枪`、`75R`、`枪`。
3. **其它**：自定义图片（长按首领图可替换成自己的图，自动裁剪为原尺寸；关闭功能时会询问是否还原）、关于里面是AI的模板。

完全离线：图片和文字都打包在应用内，断网也能用，不含任何统计或广告代码。

### 数据说明（重要）

- 所有内容（道具位置、首领数据、图片）都是我平时从各个网站、攻略图片里**手动收集整理**的，**不保证最新**。
- 当前数据整理时间：**2026.07**。
- 游戏版本更新后，哪些位置变了、哪些道具改了，我可能没跟上。**数据有偏差不是本应用的问题**，请以游戏内实际情况为准。
- 首领数据与图片源自 [trashcan.fr/freelancer](http://trashcan.fr/freelancer/)。
